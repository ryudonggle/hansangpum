# 정답셋

닭가슴살 후보 쌍에 "같음 / OEM / 다름" 정답을 단 표본이다. 라벨은 세 번 모두 Claude가 API 없이 직접 달았다(사람 라벨 아님).

| 파일 | 쌍 | 뽑은 방법 | 용도 |
| --- | --- | --- | --- |
| `닭가슴살/round1-*.json` | 50 | 결과 구간별로 골고루 | 규칙·Jev 기준값 정하기 (이 표본을 보며 규칙을 고침) |
| `닭가슴살/round2-*.json` | 140 | 1차와 겹치지 않게 5구간 층화 + 구간 크기 가중 | 과대 추정 확인 (첫 측정 재현율 59%) → 규칙을 다시 고침 |
| `닭가슴살/final-*.json` | 170 | 1·2차 레코드 341개 제외, 6구간 층화, 규칙 동결 뒤 | **최종 시험**. 한 번만 평가하고 규칙은 고치지 않음 |
| `닭가슴살/review-claude.json` | 106 | `/admin` 검수 대기 앞 100쌍 + 사람이 판정했다 지운 6쌍 | 정답셋이 아니라 **검수 판정**. 사람 대신 Claude가 판정해 묶음에 반영함 |

- `*-key.json`: 표본 쌍(품목보고번호 a·b, 구간). `final-key.json`에는 동결 해시(`frozen`)와 재현 기록(`reproduced`)도 있다.
- `*-answers.json`: 번호별 `[정답, 근거 메모]`와 라벨 기준.
- 평가 스크립트: [`scripts/eval/`](../../scripts/eval). 방법과 숫자는 [`docs/evaluation.md`](../../docs/evaluation.md).
